# Поиск изображений по текстовому описанию

Демонстрационная версия поиска фотографий по англоязычному запросу. Основная работа находится в [image_search_project.ipynb](image_search_project.ipynb): исследование данных, обучение, графики, метрики и десять примеров поиска уже сохранены в ноутбуке.

## Подход

- Признаки изображений — предобученная ResNet50 из torchvision с замороженными весами.
- Признаки описаний — TF-IDF для слов и биграмм.
- Сравниваются линейная регрессия, Ridge и полносвязные нейронные сети PyTorch.
- Обучающая, валидационная и отложенная выборки разделены по изображениям, чтобы описания одной фотографии не попадали в разные части.
- Реализованы фильтрация запрещённого контента и дисклеймер для соответствующих запросов.

## Результаты

Лучшей стала сеть с двумя скрытыми слоями: 128 и 64 нейрона.

| Проверка | Метрика | Значение |
|---|---|---:|
| Отложенные пары | RMSE | 0.2422 |
| Отложенные пары | MAE | 0.1835 |
| Отдельная галерея: 56 изображений, 280 запросов | Recall@1 | 0.0536 |
| Отдельная галерея: 56 изображений, 280 запросов | Recall@5 | 0.1893 |

Модель превосходит случайную выдачу на этой галерее, но часто ошибается. В ноутбуке разобраны ограничения разметки, метрик и примеры неверного поиска. Это прототип, а не готовый производственный сервис.

## Запуск

1. Используйте Python 3.9–3.11 и установите зависимости: `pip install -r requirements.txt`.
2. Распакуйте архив задания `dsplus_integrated_project_4.zip`. Папка `to_upload` с данными должна находиться рядом с ноутбуком. Исходный датасет не включён в репозиторий.
3. Оставьте `image_search_embeddings.npz` рядом с ноутбуком: это кэш признаков разрешённых изображений. Если удалить кэш, признаки будут рассчитаны заново.
4. Запустите `jupyter notebook` и выполните ячейки по порядку. При первом расчёте признаков torchvision загрузит предобученные веса ResNet50.

Для поиска используется функция `search_image(query)`. Примеры её работы есть в конце ноутбука. Для просмотра сохранённых результатов повторное обучение не требуется.

Проект выполнен с PyTorch 2.5.1 и torchvision 0.20.1. Численные результаты повторного обучения могут незначительно отличаться.
